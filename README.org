* 🔧  Configs for my Debian system
This repository contains my lightweight configurations for Zsh, st, Emacs, i3, and other tools I use daily. They are tailored for low-level programming and optimized to run smoothly even on older machines. It’s a minimal setup, free from heavy frameworks or flashy themes like Oh My Zsh or Doom, designed to keep development fast, clean, and efficient.

** 📥 Installation
The repository includes an =install.sh= script that automates the entire setup process. To run it:

#+begin_src 
chmod +x install.sh
sudo ./install.sh
#+end_src

** ⚙️ Utilities
The installation script also sets up a collection of lightweight, essential utilities to enhance productivity and keep the system minimal:
- =st=: fast, minimal terminal emulator
- =Emacs=: a powerful keyboard‑driven text editor
- =Dirvish=: a lightweight file manager inside Emacs
- =Luakit=: minimal web browser
- =ImageMagick=: versatile image editor and converter
- =eza=: a Rust-based ls replacement with icons
- =bat=: a modern cat replacement with syntax highlighting
- =maim=: minimal screenshot tool
- =ripgrep=: a fast grep replacement with search highlitghting
- =mpv=: fast media player

Other tools (such as =htop=) aren't installed because they can be easly replaced by Emacs

** 📐 i3

#+html: <img width="1920" height="1080" alt="wifi" src="images/wifi.png" />

Since i3 is based on X11, the application launcher is =dmenu=. Press =Super + Space= to open it, navigate with the arrow keys or type the name of an app to search, and press Enter to launch your selection.

** 💻 Terminal

#+html: <img width="1920" height="1080" alt="terminal" src="images/terminal.png" />

I applied two patches to st: one to enable background transparency and another to support scrolling. Together, they make it a minimal yet fast, efficient, and customizable terminal.

I don’t use frameworks like Oh My Zsh or unusual plugins. Instead, I’ve defined aliases to help with commands I can’t always remember, frequently used long commands, and others that make my terminal cleaner and more user-friendly.

| Alias       | Description                                                    |
| =cat=       | Maps to =batcat=, a =cat= replacement with syntax highlighting |
| =catp=      | Provides the classic =cat= command                             |
| =clearhist= | Clears zsh history                                             |
| =copy=      | Copies input to the X11 clipboard using =xclip=                |
| =rmcr=      | Removes =core.*= files generated by crashed programs           |
| =rf=        | Maps to =rm -rf=, removing files and directories               |
| =github=    | Connects to GitHub automatically using an SSH key              |
| =ls=        | Maps to =eza=, a Rust-based alternative to =ls= with icons     |
| =la=        | Lists all files in the directory                               |
| =ll=        | Lists files with additional information                        |

| =pwncheck=  | Basic PWN controls like stack canaries and non‑exec stack      |
| =webup=     | Starts a Python http server on port 8080                       |

** 📘 Emacs

#+html: <img width="1920" height="1080" alt="emacs" src="images/emacs.png" />

Emacs is configured as the central part of my development workflow. It supports several programming languages, including C/C++, Go, and Python and integrates tools such as Git, terminals, project management, file navigation, PDF viewing, and LSP-based development. It also includes a custom binary exploitation workflow with automated ELF discovery, security checks, challenge setup, and Python exploit execution and debugging.

I prefer building my Emacs setup from scratch rather than relying on frameworks like Doom Emacs or Spacemacs. I use use-package to manage my configuration, combining built-in Emacs features with external packages to get exactly what I need without adding unnecessary complexity.
- =ace-link=: makes eww navigation more powerful
- =ace-window=: fast window switching using selectable labels
- =autorevert=: automatically updates buffers when files change on disk
- =avy=: fast character-, word-, and line-based navigation
- =cape=: additional completion-at-point backends
- =consult=: enhanced commands for searching buffers, files, lines, and projects
- =corfu=: lightweight in-buffer completion
- =ctftime=: provides CTF-related functionality
- =dirvish=: enhances Dired with a modern file-management interface
- =eat=: a fully featured terminal emulator inside Emacs
- =eldoc=: displays contextual documentation for symbols at point
- =eglot=: LSP integration for programming languages
- =embark=: context-aware actions for selected objects
- =embark-consult=: integrates Embark actions with Consult
- =eww=: a built-in text-based web browser
- =helpful=: provides improved documentation for functions, variables, commands, and keybindings
- =magit=: a powerful Git interface inside Emacs
- =marginalia=: adds useful metadata to minibuffer completions
- =move-text=: moves lines and regions up and down
- =multiple-cursors=: edit multiple locations in a buffer simultaneously
- =orderless=: flexible, space-separated fuzzy-style completion
- =pdf-tools=: native PDF viewing and navigation
- =project=: built-in project management and navigation
- =recentf=: maintains a list of recently opened files
- =savehist=: persists minibuffer history between sessions
- =saveplace=: remembers the last visited position in files
- =treesit-auto=: automatically installs and configures Tree-sitter grammars
- =tramp=: transparent remote file editing over SSH and other protocols
- =undo-fu=: separate undo and redo commands
- =uniquify=: improves buffer naming when files have identical names
- =vertico=: a clean and efficient completion interface in the minibuffer
- =which-key=: displays available keybindings after pressing a prefix key
- =woman=: built-in manual-page browsing and formatting
- =yasnippet=: provides reusable code templates and snippet expansion

** 🖼️ Wallpapers

To set a new wallpaper, copy it into the =.config/wallpapers= folder, press =Super + shift + w=, and select it from the wallpaper menu. The chosen wallpaper will be saved and set as the default, so you won’t need to change it each time you log in.
